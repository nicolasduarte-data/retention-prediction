## Generation Methodology

The dataset is **fully synthetic**, generated by the `hrds/pa-workforce-analytics` pa-warehouse pipeline using a deterministic SEED=42 generator. No real employee data is used at any stage.

**HRIS signal columns** (tenure, compa_ratio, performance_tier, successor_count, age_at_window_close, gender, is_critical_role) were generated with baked-in attrition signals: low compa_ratio, short tenure, and low successor_count are correlated with voluntary exits. These signals are statistically meaningful within the synthetic dataset.

**Survey signal columns** (engagement_score, eNPS, manager_relationship_score) were added by `paw-prey-006` (2026-05-28) using a separate synthetic engagement survey event generator. Survey responses were generated for ~91.8% of employees; the remaining 8.2% have no survey response (realistic non-response rate). Survey values are correlated with engagement and retention signals in the underlying generator.

Both cohorts use the same employees, same labels, same temporal split — the ONLY difference is the feature set given to the model. This is a controlled experiment.

## Known Limitations

### 1. Censoring rate above expected range

- **Observed:** 81.2% censoring rate (1,034 of 1,274 employees still active)
- **Expected:** 55–75% per original generator spec
- **Root cause:** The synthetic generator's hire-date distribution and observation window produce a higher proportion of short-tenure employees who haven't yet had time to exit. This is a generator design artifact, not a data quality regression.
- **Impact on modeling:** Lower positive class rate (18.8%). Models will need `class_weight='balanced'` (LR) or `scale_pos_weight` (GBM) to avoid predicting the majority class. Threshold calibration and expected-value framing are adjusted accordingly in Epic 3.
- **No action required** — Loop 1 shipped successfully on the same data. Proceed.

### 2. KM median survival time above expected range

- **Observed:** KM median survival time = 45.0 months (3.75 years)
- **Expected:** ≈ 2.4 years per original design spec
- **Root cause:** Same observation-window / hire-date artifact as censoring rate. The synthetic population skews toward longer-tenured employees at snapshot date.
- **Impact on modeling:** Survival analysis in Loop 3b (rp-prey-004) should use `KaplanMeierFitter` rather than assuming a 2.4yr median. The Loop 3b benchmark should be updated to reflect the observed 3.75yr median.
- **No action required for Loop 2** — the binary classification task (exit vs. no exit) is unaffected by median tenure.

### 3. Single-snapshot temporal structure

The mart exposes a **single cross-section** (snapshot_date = 2025-05-27). This means:
- Loop 1's temporal split (80/20 by employee_id, not by time) is the only viable split strategy with this data
- True temporal validation (train on month T, predict on month T+1) requires pa-warehouse to ship time-series snapshots — currently deferred
- This is documented in SESSION_STATE.md as a "Finding flagged for Loop 2" from rp-prey-001

### 4. Survey signal high coverage (91.8%)

The paw-prey-006 acceptance criteria required ≥ 60% survey coverage. Actual coverage is 91.8% — well above floor. This means only 104 employees (8.2%) lack survey data. For the hybrid arm, these 104 rows receive median-imputed survey values from the preprocessor. Imputation quality may degrade for these rows. Documented for EDA visibility in the exploration notebook.
