**Production-grade behavioral retention prediction for senior People Analytics roles.**
Reads HRIS features from [pa-warehouse](https://github.com/nicolasduarte-data/pa-warehouse) (BigQuery), ships dual-cohort comparison + survival arm + fairness audit + interpretability deep-dive — the canonical HR exemplar most public repos don't ship.

> **⚠ SYNTHETIC data only.** All employee records are generated by the pa-warehouse synthetic data pipeline. No real HR data is involved. This artifact is decision *support*, not decision *making* — see [Forbidden Uses](#forbidden-uses) before deploying.

The market gap: most public HR retention portfolios are IBM-dataset notebooks with single-model + accuracy + no fairness + no calibration. ## Governance Disclaimer

This is **decision support, not decision making**. Predictions surface candidates for *additional human review*, not retention/termination decisions. Any deployment that automates employment decisions on this model's output violates the project's intended use.

## Limitations

- **Synthetic data only** — model behavior on real production HRIS data is unverified.
- **Single mart, single GCP project** — contract is documented at `docs/integration_contract.md`; portability to other warehouses (Snowflake, Redshift) ships in pa-warehouse's parity tracks.
- **Causal claims** — none. This model is Rung 1 (associational) per the Rubenstein 2017 / Pearl ladder framing. SHAP + DoWhy slice is held for v1.1 only if reviewer feedback specifically asks.

## How to Run

```bash
# Prerequisites: Python 3.11+, uv (https://docs.astral.sh/uv/), git
git clone https://github.com/nicolasduarte-data/retention-prediction.git
cd retention-prediction

# Install
uv sync

# Configure BigQuery (cross-platform)
cp .env.example .env
# Edit .env to set PA_WAREHOUSE_SA_KEY pointing at your GCP service account JSON

# Verify environment
uv run pytest                                              # 6 behavior tests
uv run pytest --nbmake notebooks/00_environment_check.ipynb # env + BQ auth smoke
uv run pre-commit run --all-files                          # 6 hooks must pass
```

For deterministic reproducibility:
```bash
PYTHONHASHSEED=42 uv run pytest
```

See `.env.example` for the full env-var contract.
